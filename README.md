# Kollol Chakraborty — 3D Portfolio

Scroll-driven editorial portfolio. Next.js 16 (App Router), React 19, React Three Fiber 9, Tailwind v4.

```bash
npm run dev     # http://localhost:3000
npm run build
npm run lint
npx tsc --noEmit
```

- Design tokens: `src/app/globals.css` (DOM), `src/styles/tokens3d.ts` (3D)
- Architecture, rig notes, content gaps: `docs/ARCHITECTURE.md`
- Assets: `public/models/avatar.glb`, `public/resume.pdf`
